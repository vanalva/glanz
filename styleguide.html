10 · Responsive

Breakpointless design

All type and spacing use clamp() over viewport 20–90rem. Three breakpoints remain as max-width fallbacks for true layout shifts.

NameMedia queryWebflow variant key
Desktopbase — no media querymain (default)
Tablet@media (max-width: 991px)medium
Mobile Landscape@media (max-width: 767px)small
Mobile Portrait@media (max-width: 478px)tiny

Never use min-width. Never use @container. Never invent custom breakpoint values. Webflow is desktop-first and only these three stops exist.
